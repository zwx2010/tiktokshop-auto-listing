# 72 秒公开演示

该演示用于 GitHub 首页和求职作品集，集中展示最直观的飞书业务闭环：运营发送自然语言指令、机器人执行并回传审批卡、人工授权、发布结果回调，以及多维表格结果回写。

- 所有数字、商品与任务均为脱敏样例数据。
- 页面右上角始终标注“公开演示”。
- 不读取数据库、商家信息、令牌或本地配置。
- 六个画面各停留 12 秒，总时长 72 秒。
- 界面按项目真实工作流结构制作，但不是商家生产环境录屏。
