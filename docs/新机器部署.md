# 移植到另一台机器:部署清单

目标:把「@上架机器人 → 采集→制表→审图→审批→上架」这套 agent 在另一台 Windows 机器上跑起来。

> ⚠️ **影刀不需要**（旧 PDD 采集已弃用，2026-08-11）。当前采集走 1688 + Edge CDP（RoseSeek 兄弟包），新机器**不用装影刀、不用装任何 RPA**。

**结论先行** —— 移植分三档:

| 档 | 内容 | 难度 |
|---|---|---|
| ① 直接拷 | 代码 + 数据库 + RAG 索引 + 技能包 | 拷目录 |
| ② 要装 | Python、Claude Code CLI、Edge、cpolar | 半小时 |
| ③ 卡死 | TikTok 卖家后台登录态、1688 登录态 | 新机器重新登录,不可拷 |

---

## 一、要拷的东西(整目录拷贝)

```
TikTokShop_Platform/            ← 整个项目
├─ app/                         ← FastAPI 服务 + agent 编排
├─ tools/                       ← 平台侧工具(export 上架表等)
├─ scripts/                     ← 建 RAG 索引等
├─ config/                      ← 含 feishu.local.json(密钥,见"安全注意")
├─ data/                        ← platform.db + rag_corpus.db
├─ requirements.txt
├─ 一键启动.bat
└─ docs/

RoseSeek_TikTokShop_AI_Localized_20260809/   ← 兄弟包(采集/审图/上架 CDP 脚本),同样整目录拷
```

**技能包**(`claude -p` 加载,拷到新机器用户目录,路径必须一致):
```
~/.claude/skills/
├─ rag-knowledge
├─ tiktok-capture
├─ tiktok-table
├─ tiktok-review
├─ tiktok-approval
├─ tiktok-upload
└─ tiktok-3site-upload
```

## 二、新机器安装

### 1. Python
装 3.10+ 并加入 PATH。

### 2. 项目依赖
```
cd TikTokShop_Platform
pip install -r requirements.txt
```
核心依赖:fastapi / uvicorn / sqlalchemy / openpyxl / requests / pycryptodome(AES 解密飞书载荷)。

### 3. Claude Code CLI —— 大脑,必装
```
npm install -g @anthropic-ai/claude-code
claude           # 首次运行完成登录/授权
```
agent 的"大脑"通过 `claude -p` 无头调用;新机器不登录就无法理解指令、无法执行各 stage。

### 4. Edge/Chrome
采集(1688)和上架(TikTok 卖家后台)都是 CDP 驱动 Edge,需装 Edge。

### 5. cpolar(飞书回调需要公网)
飞书 webhook 要公网地址,cpolar 穿透 8000 端口(由用户自己在终端 `cpolar authtoken <token>` 登录)。

## 三、路径配置(只需两处,可不改代码)

代码里**硬编码的绝对路径只有 2 处**,都用环境变量可覆盖:

| 环境变量 | 含义 | 缺省 |
|---|---|---|
| `ROSEEK_PKG_DIR` | RoseSeek 兄弟包目录 | `D:/ccproject/codeproject/RoseSeek_TikTokShop_AI_Localized_20260809` |
| `PLATFORM_DIR` | 本平台目录 | `D:/ccproject/codeproject/TikTokShop_Platform` |

新机器如果目录结构不同,启动前 `set` 一下即可,不用改代码:
```bat
set ROSEEK_PKG_DIR=D:\your\path\RoseSeek_TikTokShop_AI_Localized_20260809
set PLATFORM_DIR=D:\your\path\TikTokShop_Platform
```
其余路径(`BASE_DIR`、`data/`、`config/`)都是文件相对推导,随目录搬家自动生效。

## 四、账号登录(卡死的部分,必须手工做)

以下**不能拷**,是新机器首次使用时手动登录一次,之后 CDP profile 才存在:

1. **TikTok 卖家后台**(`tools/Start-TikTokAffiliateBrowser.ps1 -ProfileName tiktok_affiliate_accessories_3site`)
   打开浏览器 → 登录卖家账号 → 保持 profile。不登录,上架 stage 就会失败。
2. **1688 采集**(`tools/Start-1688Browser.ps1` 调试端口 9223)
   登录 1688 账号。不登录,采集 stage 采不到数据。

> 如果新机器只做**采集/制表/审图**(不含真上架),TikTok 卖家登录可以跳过——装好 Claude Code 登录即可跑通大部分流程。

## 五、启动 + 验证

```bat
:: 设置路径环境变量(如目录不同)
set ROSEEK_PKG_DIR=...
set PLATFORM_DIR=...

:: 启动后端(或双击 一键启动.bat —— 自动 cd 到项目根,免改路径)
python -m uvicorn app.main:app --port 8000
```

验证:
1. `http://127.0.0.1:8000/dashboard/` 打开后台看板
2. 飞书群发 `@上架机器人 你好` → 应回灰卡「没法执行」(验证 interpret/reject)
3. 飞书群发 `@上架机器人 泰国店上2个耳环` → 应回审批卡,首行显示「泰国 TH / 上架 / 目标2」
4. 点「通过全部」→ 真上架(需 TikTok 卖家已登录)

## 六、安全注意

- `config/feishu.local.json` 含 **app_secret / verification_token** → **不要进 git、不要外传**;换新机器建议到飞书开放平台重置。
- 数据库里的商品数据是业务数据,传输注意加密(U盘/内网)。
- `claude` 登录用你个人账号;确认无敏感会话。

---

## 排错速查

| 现象 | 原因 |
|---|---|
| 飞书回调 401 signature mismatch | 缺 `ALLOW_UNVERIFIED=1` 或验签配置不对(仅测试可绕过,生产别开) |
| 上架 stage 失败 | TikTok 卖家未登录 / profile 不存在 / Edge 未装 |
| 采集 stage 采不到 | 1688 未登录 / 9223 端口被占 |
| interpret 全走正则兜底 | `claude -p` 未登录或 CLI 未装 |
| 审批卡不弹 | cpolar 穿透没起 / webhook 地址没配到飞书后台 |
