# 真实联调与测试发布运行手册

本项目的本地页面只做只读诊断；运营入口是飞书多维表格。任何发布前必须完成以下顺序：

1. 运行四项无副作用探针：`feishu`、`ai`、`cdp`、`tiktok`，四项均为 `confirmed`，且确认时间不超过 24 小时；配置变更后必须重跑。
2. 在飞书审批卡核对账号、站点、候选清单、数量、门禁结果和回滚方案。
3. 独立人工批准后，调用 `validate_test_release`，单批数量必须 `1..50`。
4. 仅在批准门返回 `eligible=true` 时启动真实 CDP/TikTok 上架；每件结果回写飞书，批次级无法定位时标记“上架待核对”。
5. 失败或需撤回时，按批准卡中的回滚方案停用对应 listing，并保留审批审计和平台追踪 ID。

当前仓库已完成代码与无副作用自动化验证；未在缺少四项真实凭据和独立人工批准时执行发布。
