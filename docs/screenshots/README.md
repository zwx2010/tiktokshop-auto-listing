## ⚠️ 截图前必做的脱敏（重要）

这些数据是**真实的**，截之前先看画面里有没有：

- 真实商家 / 店铺账号名 → **打码或遮挡**
- 真实价格、成本、SKU 明细 → 可留商品名，价格栏建议打码
- 飞书群的群名 / 头像 / 成员昵称 → **务必打码**
- 任何 URL、令牌、端口号 → 打码

**原则：画面里只能出现"系统能力"，不能出现"你的经营信息"。**
