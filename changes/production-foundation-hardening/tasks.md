# 实施任务

## Delivery / Proof Map

| 需求 | 交付物 | 证据 |
|---|---|---|
| 持久化任务事实源 | API/Repository/worker 统一 | API→MySQL worker 重启测试 |
| 并发与恢复 | 原子领取、租约、幂等键 | MySQL 双 worker、过期租约测试 |
| 飞书运营控制面 | 字段校验、状态投影、重试与审批 | Bitable mock/API 契约测试、人工演练清单 |
| 真实联调门 | 四项探针与发布批准限制 | 无副作用探针记录、批准卡和上限测试 |
| 只读诊断与安全日志 | 诊断页收敛、脱敏器 | 路由/日志负向测试 |

## Tasks

1. **固化基线与未提交修复**（范围：现有 `git diff`、`tests/`、`changes/`）
   - 盘点并归类图片解析、Decimal 定价、图片回填和导出兼容修复；补齐回归测试并建立可回退基线。
   - 证据：`git diff --check`、`python -m pytest -q`、基线清单。

2. **统一持久化任务 API 和 worker**（依赖：1；范围：`app/api/`、`app/application/`、`app/infrastructure/`、`app/jobs/`）
   - 用 MySQL Repository 替换 API 内存任务服务，支持创建、读取、幂等、日志与受控状态迁移。
   - 证据：API 创建任务后由独立 worker 消费、重启恢复测试。

3. **实现并发领取、租约恢复与审批审计**（依赖：2；范围：`app/models.py`、`migrations/`、`app/agent/approval.py`、Repository）
   - 增加审批/发布审计持久化；以数据库原子语义领取任务、恢复过期租约，并将重复回调变为幂等结果。
   - 证据：MySQL 并发、租约过期、重复回调、重启后审批恢复测试；Alembic upgrade/downgrade。

4. **完成飞书多维表格运营控制面**（依赖：2、3；范围：`app/feishu/bitable.py`、`app/agent/bitable_flow.py`、`scripts/`）
   - 校验和迁移运营字段；实现数据库优先的状态投影、失败回写、人工重试、批准人/时间与任务关联。
   - 证据：字段诊断、状态机契约测试、回写失败恢复测试、飞书沙箱演练记录。

5. **建立真实集成探针与发布批准门**（依赖：3、4；范围：`app/integrations/`、`app/routers/`、`app/agent/`）
   - 实现飞书、AI、CDP、TikTok 的非发布探针及 24 小时有效期/配置变更失效规则；生成含候选清单、账号、市场、数量、门禁与下架方案的批准数据，并强制每批不超过 50 件。
   - 证据：无凭据、失败、confirmed 探针测试；超限拒绝与批准审计测试；真实连通记录。

6. **收敛诊断页和日志安全**（依赖：2、4、5；范围：`app/routers/`、`app/templates/`、日志工具、`docs/`）
   - 移除本地运营入口，仅保留健康、任务、集成和安全失败摘要；集中脱敏所有入站/出站日志。
   - 证据：只读路由测试、敏感字段日志负向断言、文档审阅。

7. **真实测试发布与发布后验证**（依赖：5、6；范围：运行配置、飞书表、CDP/TikTok 环境）
   - 在四项探针 confirmed、候选清单审阅和独立人工批准后，执行最多约 50 件测试商品的发布；逐件回写结果并验证下架方案。
   - 证据：人工批准记录、任务审计、飞书回写、平台追踪 ID、异常商品处置记录。

8. **全量回归与交付收尾**（依赖：1–7；范围：测试、迁移、README、部署文档）
   - 完成全量自动化测试、MySQL 迁移/外键验证、运行手册、失败恢复演练与交付报告。
   - 证据：测试报告、Alembic 头版本、验证清单和脱敏的真实联调报告。

## Dependency Order

`1 → 2 → 3 → 4 → 5 → 6 → 7 → 8`；任务 6 可在任务 5 的实现后并行完成，但任务 7 必须等待任务 5、6 和独立人工批准。
